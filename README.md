# سایت کاتالوگ

پریویو ورق‌خورِ راست‌به‌چپ برای کاتالوگ ۲۴×۱۷ افقی، با امکان جابه‌جایی بین چند ورژن.

صفحات از قبل به تصویر تبدیل می‌شن (`build.py`) و سایت فقط عکس نمایش می‌ده — چون رندر PDF
داخل مرورگر (pdf.js) روی بعضی خروجی‌ها گیر می‌کنه و لود چندمگابایتی هم کنده.

## اضافه کردن یا به‌روزرسانی کاتالوگ

۱. فایل PDF رو داخل `catalogs/` بذار. **اسم فایل همون چیزیه که توی دکمه‌ی انتخاب ورژن دیده می‌شه**،
   پس مثلاً `نسخه ۱.pdf` یا `Story.pdf` صداش کن.

۲. یک‌بار اجرا کن:

```bash
pip install pypdfium2 pillow
```

```bash
python build.py
```

این کار `pages/<اسم>/001.jpg …` و `pages/manifest.json` رو می‌سازه. هر بار PDF عوض شد، دوباره اجراش کن.

## تست لوکال

```bash
python -m http.server 5173
```

بعد برو به `http://localhost:5173`

## انتشار روی گیت‌هاب پیجز

۱. کد رو به یه ریپوی گیت‌هاب push کن (پوشه‌ی `pages/` هم باید commit بشه).
۲. تنظیمات ریپو → Pages → Branch: `main`، Folder: `/ (root)`.
۳. لینک نهایی: `https://<username>.github.io/<repo>/`

## تنظیمات

- کیفیت/اندازه‌ی تصاویر: `TARGET_W` و `QUALITY` بالای [build.py](build.py).
- نسبت صفحه (۲۴:۱۷) و ابعاد کتاب: `PAGE_W` / `PAGE_H` بالای [app.js](app.js).
